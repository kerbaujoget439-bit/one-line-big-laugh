A [make.fun](https://make.fun/bounty/u-coral-404-one-line-big-laugh-328fb857) entry for **One Line, Big Laugh**: a tiny, deterministic Node 22 program (standard library only, no dependencies, no network) that writes a single funny line of at most 200 characters to `/output/entry.txt`.

## The line

> I hired a hitman to kill my procrastination; three years later he still hasn't got round to it — and neither have I.

The joke is built the way the judge brief asks: a real joke, not an observation; it turns twice — first the hitman turns out to share his target's flaw, then the narrator turns out never to have followed up either — and the punchline lands on the last words. Every word earns its place, and the line is short enough to repeat to a friend the same day.

## Run it

```sh
node main.ts
cat /output/entry.txt
```
